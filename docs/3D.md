# Kinora 3D — design and plan

Kinora 3D brings modeling, materials, lighting and animation into Kinora with the same
promise as the photo/video editor: **a beginner makes something they're proud of in
minutes, and a professional never hits a ceiling that makes them leave.**

## Who it is for

| Person | What they need | How Kinora 3D serves them |
| --- | --- | --- |
| First-timer ("what is a mesh?") | Results without jargon | Goal-first starts, one-tap shapes and materials, magic lighting, turntable videos, a tour that waits until you've done each step |
| Hobby animator | Keyframes that just work | Auto-key, one-tap motion presets (spin, bounce, float, pop-in), easing chips, onion-free dope sheet |
| Pro animator | Speed and control | Blender keymap (G/R/S with axis + numeric input, I to key, Alt+G/R/S reset), per-key interpolation, pose mode on rigged glTF/FBX characters, clip playback |
| Game artist (AAA pipeline) | Clean, light, engine-ready assets | Quad modeling (extrude, inset, loop cut, bevel), modifier stack (mirror, subdivision, array, solidify, decimate, triangulate), PBR texture maps, polycount stats, **Game-ready check**, GLB export with animations |

## Principles

1. **Two depths, one tool.** Every action has a big labeled button *and* a pro shortcut.
   Beginners never need the shortcuts; pros never need the buttons.
2. **Plain words first, real words second.** "Pull out (Extrude)", "Smooth it (Subdivision)".
   Pros see the industry term; beginners learn it.
3. **Non-destructive by default.** Modifiers stay editable until applied; every edit undoes.
4. **Standards in, standards out.** glTF/GLB is the native interchange (Unity, Unreal,
   Godot, Blender, the web). FBX, OBJ, STL, PLY import; OBJ, STL and USDZ (AR) export.
5. **Same quality bar as the 2D editor.** Physically based materials, filmic (AgX) tone
   mapping, soft shadows, image-based lighting; what you see is what renders.

## Architecture

```
src/studio3d/
  model/     pure, unit-tested data: scene graph, polygon meshes, mesh operations,
             Catmull-Clark subdivision, modifier stack, keyframe animation, materials
  state/     signals store, undo/redo (snapshot history shared with 2D), actions, autosave
  engine/    three.js viewport: model → scene sync, picking, edit-mode overlays,
             gizmos + Blender-style modal transforms, environments, import/export, renders
  ui/        studio layout, outliner, properties, timeline/dope sheet, dialogs
```

**Data model.** A `Scene3D` is plain data (structured-clone friendly, stored in IndexedDB):
objects in a flat map with parent ids, materials, textures (blobs in the shared media
store), environment, render settings and the animation range. Meshes are *polygon* meshes
(n-gons, not just triangles): positions `Float32Array`, face corners `Uint32Array` + face
sizes, per-corner UVs and per-face material slots. Edits return new arrays and unchanged
parts are shared, so undo snapshots are cheap — the same idea as the 2D model.

**Mesh operations** (all pure functions): transform selection, extrude region, inset,
delete verts/edges/faces, merge (center / by distance), loop cut on quad rings, bevel
edges, subdivide, fill, flip / recalculate normals, box-UV projection.

**Modifier stack** evaluated on demand and cached by input identity: Mirror (with seam
merge), Array, Solidify, Subdivision (Catmull-Clark), Bevel, Decimate, Triangulate,
Smooth-by-angle shading.

**Animation.** Keyframes per object channel (location, rotation, scale; light intensity;
camera field of view), each key with its own interpolation (constant, linear, ease,
ease-in, ease-out, back, bounce, elastic). Imported glTF/FBX clips play through three's
`AnimationMixer`; pose-mode bone keys are stored like object keys and baked into
`AnimationClip`s for GLB export.

**Rendering.** One `WebGLRenderer` per viewport, rendering on demand. Shading modes:
solid, material preview, rendered (soft shadows), wireframe/x-ray. Environments: studio,
sunset, overcast, night (generated, so they work offline) or any HDR/EXR file. Image
and video renders reuse the 2D editor's WebCodecs exporter.
